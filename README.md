# San Diego Glass Specialist

A simple project repository for the San Diego Glass Specialist business website and marketing site.

## Overview

San Diego Glass Specialist provides glass repair, replacement, and installation services for residential and commercial properties throughout San Diego County. This repository can serve as the foundation for a brochure-style website, landing page, or lead-generation site.

## Services

- Window repair and replacement
- Shower door installation and repair
- Storefront and commercial glass
- Residential glass services
- Emergency glass repair
- Custom glass solutions

## Mission

To deliver dependable, professional glass service with fast response times, honest pricing, and quality craftsmanship.

## Project Structure

This repository is intentionally lightweight and can be expanded to include:

- `index.html` for the main marketing page
- `styles.css` for branding and layout
- `script.js` for menu, animations, or contact form interactions
- `assets/` for images, logos, and product photography

## Local Development

To preview the site locally:

1. Clone the repository
2. Open the project folder in your editor
3. Launch a local web server (or open `index.html` directly in a browser)

Example using Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
